胸部X光肺炎分类 · Chest X-ray Pneumonia Classification

用 ResNet-18 迁移学习区分正常胸片与肺炎胸片。这个仓库的重点不在"刷高指标"，而在**评测是否可信**：按病人切分、阈值只在验证集上选、测试集只跑一次。

> ResNet-18 transfer learning for NORMAL / PNEUMONIA classification, with a reproducible patient-level split and a single, honest test evaluation.

## 结果 · Results

测试集 **624 张（官方划分，全程只跑一次）**：

| 指标 | 数值 |
|---|---|
| **AUC** | **0.9801** |
| 工作点 A（Youden，阈值 0.89） | 敏感度 99.2% / 特异度 72.7% / 准确率 89.3% |
| 工作点 B（筛查，阈值 0.47，漏诊 ≤1%） | 敏感度 99.7% / 特异度 59.0% / 准确率 84.5% |

验证集（798 张，与训练集病人不重叠）：AUC 0.9995（第 4 轮最优）。

> 两个数字差这么多不是错，是两批数据的分布不同——见下面「已知问题」第 1、2 条。

## 已知问题 · Limitations（这部分比结果重要）

1. **阈值不能跨数据集搬运。** 在验证集上选出的阈值（0.89）拿到测试集上，特异度从 100% 掉到 72.7%；而 AUC 只从 0.9995 掉到 0.9801。原因：AUC 只看排序、与阈值无关；阈值是绝对概率刻度，换一批数据就会整体偏移。**落地时必须在目标人群上重新标定阈值**，这也是医疗器械注册里"阈值验证"要单列一项的原因。
2. **数据集存在采集偏倚。** 正常片与肺炎片来源不同：正常片中位 1666×1380、肺炎片中位 1168×776。只用图像的宽高/宽高比训练逻辑回归，验证集 AUC 就到 **0.927**；只用 resize 后的清晰度（拉普拉斯方差）一个特征，AUC 就有 **0.93**。也就是说模型可以靠"糊不糊、多大"拿分，而不是靠病灶。这不是本仓库能修的，是数据本身的属性，任何在这个数据集上报高 AUC 的工作都该打这个问号。
3. **验证集偏乐观。** 验证集从 `train` 中切出，与训练集同源；官方 `test` 是另一批图像。所以 0.9995 只是"同源数据上的上限"，能对外报的是 0.9801。
4. **标签是图像级、不是病灶级。** 只有"这张片子有没有肺炎"，没有病灶位置，因此不能直接回答"模型看的是不是病灶"。遮挡实验只能粗略提示：只留中心（肺野）时 AUC 0.9496，只留边框 0.8923。

## 数据 · Dataset

- 来源：Kermany et al. 2018, *Large Dataset of Labeled OCT and Chest X-Ray Images*（Mendeley Data: rscbjbr9sj，CC BY 4.0）
- 训练池 5232 张（正常 1349 / 肺炎 3883），测试集 624 张（正常 234 / 肺炎 390）；官方未提供可用的验证集（原版 val 仅 16 张）
- 划分方式：**按病人**从训练池切出 15% 做验证 → train 4434 / val 798；病人零重叠（肺炎患者常有多张片子，按图片切会泄漏）

## 方法 · Method

1. ResNet-18（ImageNet 预训练）+ 替换最后一层为 2 类；输入 128×128
2. **ImageNet 归一化**（mean 0.485/0.456/0.406、std 0.229/0.224/0.225）——预训练权重的要求，早期版本漏了这一步
3. 数据增强（仅训练集）：随机裁剪缩放、±7° 旋转与平移、50% 概率高斯模糊。**不做水平翻转**——胸片镜像会把心脏翻到右侧，解剖上错误
4. 训练 5 轮、Adam、lr 1e-4；按**验证集 AUC** 选最优轮次（第 4 轮），保存权重
5. 阈值在验证集上扫（步长 0.01），测试集只评估一次

## 与早期版本的差异

早期版本（2026-09）报的是 AUC 0.95、敏感度 100% / 特异度 55~64%。**那一版的阈值是在测试集上扫出来的**——相当于用答案选参数，数字偏乐观且无法复现。本版修正了这一点：

| | 早期版本 | 本版 |
|---|---|---|
| test AUC | 0.95 | **0.9801** |
| 阈值来源 | 测试集（泄漏） | 验证集 |
| 图像归一化 | 无 | ImageNet mean/std |
| 划分 | 按图片（病人泄漏） | 按病人 |
| 可复现 | 否（无种子） | 是（seed 42） |

提升来自三处：归一化、按病人切分、按验证集选轮次。**换更复杂的模型不是优先项**——这个数据集的瓶颈在标签与采集偏倚，不在模型容量。

## OOD 拒识（实验性）

`train_ood.py`：在正常/肺炎之外加第三类 `OTHER`（300 张合成非胸片：噪声/渐变/几何图形/条纹/棋盘格），使模型遇到非胸片时提示而非瞎猜。

- 结果：300/300 全部被识别为 `OTHER`
- 代价：三分类使正常类特异度从 55~64% 降至 45%
- **这个结果要打折看**：合成图只有 5 种模板，模型学到的更可能是"条纹/棋盘格长这样"，而不是"这不是胸片"。换成真实照片/截图后拒识率大概率会掉
- 改进方向：两级级联（先"是否胸片"二分类把关，再肺炎二分类），可保留拒识而不伤原任务

## 讨论 · Discussion

- **为什么报 AUC 而不只报准确率**：类别不平衡（肺炎占 74%）时，全判"肺炎"就能拿到 74% 准确率；AUC 衡量排序能力，不受阈值和类别比例影响
- **为什么必须按病人切分**：同一病人的多张片子共享体位、曝光、纹理，按图片切会让验证集"见过"同一病人的其他片子。本数据集实测：按图片随机切时，59% 的验证图片其病人也在训练集里
- **阈值为什么不能搬**：模型输出的概率依赖训练分布，换数据源后整体偏移，同一个阈值的含义就变了。AUC 稳定、阈值不稳定，是两件事
- **过拟合信号**：训练 loss 持续下降而验证指标回落即开始过拟合（本任务第 4 轮后已出现）

通过调整决策阈值，可在两种临床场景间权衡：低阈值用于**筛查**（宁多不漏），高阈值用于**确诊**（避免误诊）。

## 数据 · Dataset

- 来源：Kermany et al. 2018, *Large Dataset of Labeled OCT and Chest X-Ray Images*（Mendeley Data: rscbjbr9sj，CC BY 4.0）
- 规模：训练集 5232 张，测试集 624 张（正常 234 / 肺炎 390）
- 格式：JPEG 灰度胸片，`NORMAL` / `PNEUMONIA` 两类

## 方法 · Method

1. **ResNet-18 迁移学习**：ImageNet 预训练权重 + 微调最后一层（1000 类 → 2 类）
2. **类别不平衡处理**：对比了 class_weight、欠采样、阈值调优三种方案，最终采用**阈值调优**
3. 输入尺寸 128×128，训练 5 个 epoch

## 消融实验 · Ablation Study

### ① 分辨率 × 训练轮数（Resize × Epochs）

| 配置 | 阈值0.9 特异度 | 结论 |
|------|------|------|
| **128 × 5 轮** | **71~74%** | ✅ 最终采用 |
| 128 × 10 轮 | 63.7% | 过拟合（训练 loss → 0.0005）|
| 224 × 5 轮 | 66.7% | 无显著提升 |
| 224 × 15 轮 | 54.3% | 严重过拟合（loss → 0.0001）|

**结论**：更多训练轮数 ≠ 更好。当训练 loss 持续下降到接近 0、而测试指标掉头向下，即过拟合（模型在"背答案"而非"学规律"）。本数据集约 5200 张，5 轮即为甜点区；且 224 分辨率反而更容易过拟合（细节更多、可背的东西更多）。

### ② 类别不平衡处理方案（Imbalance Handling）

| 方案 | 效果 |
|------|------|
| **阈值调优** | ✅ 最优：不改模型，只调决策阈值，敏感度/特异度可自由权衡 |
| class_weight | 未改善（weight=[3,1] 时特异度反降至 44%）|
| 欠采样（肺炎砍到与正常等量）| 未改善（特异度 44%，丢弃 2/3 肺炎数据反而模糊了决策边界）|

## OOD 拒识 · Out-of-Distribution Detection

为让模型遇到"非胸片"输入时能提示而非瞎猜，实现了 out-of-distribution 拒识：在正常/肺炎之外增加第三类 `OTHER`，用 300 张合成非胸片（噪声 / 渐变 / 几何图形 / 条纹 / 棋盘格）训练。

- **效果**：300 张合成非胸片 **100% 被正确拒识**（全部判为 OTHER）
- **代价（tradeoff）**：三分类使原任务的正常类特异度从 55~64% 降至 45%——单一模型做三分类的固有代价
- **改进方向**：两级级联（先"是否胸片"二分类把关，再肺炎二分类）可在保留拒识的同时不伤原任务

## 讨论 · Discussion

- 类别不平衡会让模型偏向多数类：敏感度虚高、特异度低，单看准确率会被误导
- 处理不平衡只能在训练阶段（重采样/加权）或决策阶段（调阈值），不能在测试集上做手脚
- 过拟合信号：训练 loss 持续下降、测试指标掉头向下；本任务中 5 个 epoch 即为最优
- 224 与 128 无显著差异、更多轮数反而过拟合——瓶颈在数据本身的标签噪声，不在模型容量
